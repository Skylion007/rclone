# Modal Volume

The `modal` backend transfers files to and from an existing [Modal Volume](https://modal.com/docs/guide/volumes). Both Volume versions are supported for file transfers.

## Configuration

Install the Modal SDK in Python 3.11 or later. Authenticate with a Modal profile or set `MODAL_TOKEN_ID` and `MODAL_TOKEN_SECRET` in the environment.

```sh
python3 -m pip install 'modal>=1.6.4'
modal token new
rclone config create models modal volume model-weights environment main
```

Set the remote's `python` option to the SDK environment's Python executable if it differs from `python3`. Omit `environment` to use Modal's default environment. You can also configure `volume_id` in place of `volume` and `environment`.

Paths are relative to the selected Volume.

```sh
rclone lsf models:checkpoints --recursive --fast-list
rclone copy ./checkpoints models:checkpoints
rclone copyto models:checkpoints/model.safetensors ./model.safetensors
rclone sync ./checkpoints models:checkpoints --dry-run
```

## Limitations

- Uploads stage one temporary local file per transfer. Allow local disk space for the largest concurrent uploads.
- The backend reads Modal's modification times. Modal assigns them on upload, so repeated syncs can transfer unchanged files again. For content verification, use `rclone check --download`.
- Parent directories are created on upload. Empty directory creation is unavailable. Volume v2 supports removing empty directories. Volume v1 requires recursive deletion for directories, so rclone may leave empty directories behind and report a directory removal error.
- The SDK streams downloads from the beginning of each file, including reads with an offset. Parallel range downloads and server-side copies are unavailable.
- Listings include directories and regular files. Symbolic links and other special entries are skipped.
